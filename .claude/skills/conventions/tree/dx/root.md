# What are you adding?

Answer once per thing the work adds.

- A routed page (`*.page.tsx` or `*.outlet.tsx`) → [page](page/index.md)
- A component body → [view](view/index.md)
- Words a user reads → [copy](copy/home.md)
- A hook, util or type with no network or push → [logic](logic/no-copy.md)
- A service entry, or a query or mutation in `use<Domain>.ts` → [service](service/index.md)
- A view that updates when the server pushes → [push](push/index.md)
