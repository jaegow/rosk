# Action

- A commit, at the bottom of a view or in a modal footer → [commit](commit.md)
- A control acting on a panel's or card's own content → [panel](panel.md)
- An action on one row of a collection → [row actions](../collection/row-actions.md)
- A page-level action that is not a commit (New, Export) → [page actions](../surface/page-actions.md)
- One of several peers where exactly one is chosen, not a view switch → [select](select.md)
- A switch between views of a page, modal or card → [head tabs](../surface/head-tabs.md)
- A file upload → [upload](upload.md)
- A filter in a collection's filter bar → [filters](../collection/filters.md)
