# Prompts

A prompt is the small dialog asking one question before an action.

- One section: its text, then rows of data or the few fields the action needs; never cards, a list to choose from, links or row actions.
- A confirm that must show more is a regular-width modal as tall as its content up to 90% of the window.
- Its foot CTAs sit on one line; Cancel and the commit show their whole label, a tertiary one truncates.
- A state about what it acts on is its head status; a foot message only a consequence of the press.
- It never shows only a wait: what it needs is read before it opens, and a failed read fails where it was started.
- A confirmed value reads as the reader knows it: the field's label and shown value, old to new.
