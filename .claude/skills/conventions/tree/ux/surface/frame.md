# Frame

- Compose a page from its layout slots and add nothing around them.
- Lay a page's short cards in one card grid; a card needing the width takes the whole row, after them; a card holding a table gets the width its columns need.
- A card's look follows the layout it sits in, never the page: raised in a grid, outlined in a form, dashed for an empty state, the overlay look over the page.
- A short card lists values as rows; a whole-row card as a field grid.
- Lay like cards (the same sections for different records) in an aligned row so sections sit level.
- Lead with what the reader acts on or checks first; end with reference detail.
- Keep a page's bodies of work on one page while it reads without hunting; give one a routed tab only when it would crowd the page.
- A page is one column unless it shows evidence beside its fields.
- A list page never scrolls whole: the table owns its scroller.
- A list column's head (title and add) sticks while its records scroll; the add is the group's one create trigger.
- With nothing selected, a list's detail pane is its header line alone, saying to select a record, or that there are none yet.
- A horizontal scroller that overflows also scrolls by mouse drag on its non-control surface.
