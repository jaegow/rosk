# Responsive

- Build for desktop widths; never rearrange into a phone layout.
- Reflow at 400% zoom: text and forms in one column with no sideways scroll; a table may scroll sideways.
- Size a component to its container, never the viewport.
- A one-line ellipsis fits only where the full text is reachable another way; show its tooltip only while the text is cut, and keep the cut text out of the tab order.
