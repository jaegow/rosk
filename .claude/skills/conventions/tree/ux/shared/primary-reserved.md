# Primary is reserved

- `primary` appears only in a page's or a modal's footer, a step's commit in a multi-step flow, a filter bar's action, or a Save in any footer.
- Anywhere else (a card or panel footer, a section head, a toolbar, a row) the strongest CTA is `secondary`.
- Never reach `primary` by state.

Why: `primary` says where the view moves on; worn twice, it answers nothing.
