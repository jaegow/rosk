# Message

- A decision or input needed to finish an action the user just started → [modal](modal.md)
- The outcome of a request the client sent, or a message whose only control would be Dismiss → [toast](../toast.md)
- State one card or modal holds, still needed and acted on there → [alert](alert.md)
- A short status on one field or entity → [chip](chip.md)
- About one form field's value → [field](field.md)
- Optional help about one control or label → [info](info.md)
- State of the whole page's, modal's or card's record that holds until it changes → [header band](header-band.md)
- A sentence that changes which footer CTA the user presses, or what they expect → [footer band](footer-band.md)
- App-wide state tied to no record → [banner](banner.md)
