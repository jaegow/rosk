# Alert

- System-raised state the user must act on or relay sits in the head status of the smallest view it is about (a card, a modal, the page), for as long as the state holds.
- An alert is only ever the band a head's status host draws, full-bleed across the foot of that head; never place one as a box inside content.
- Give it the CTAs that resolve it; a card with no head takes one holding only its statuses.
- An inline alert is static, with no live role; announce a change through a toast, or a status built on `<output>`.
- The outcome of a request is a toast, never an alert.
