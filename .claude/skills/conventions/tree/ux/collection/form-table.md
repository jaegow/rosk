# Form table

A form table's cells hold form fields, one row per line the reader edits.

- Every row is one height, holding one reserved message line under every field, so a message never moves the row.
- Line every cell up on the inputs' line.
- Show every line on one page, unsorted and unfiltered, in the form's order.
- Name each field by its column header, then its line.
- Offer a line's single choice as a select.
- Add a line from the section's head; it shows as the first row. Remove without asking: Cancel restores it.
- Keep focus on a Move Up or Move Down as its line moves; at the boundary the press warns.
