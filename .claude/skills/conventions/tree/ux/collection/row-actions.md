# Row actions

- Name an action that opens one record by what the user arrives to do: `review` to decide something, `view` read-only, `edit` with fields editable; vary it per row and per user from the same check the destination makes.
- Never name an action that commits on click `review`.
- Start a row action's accessible name with its visible or tooltip word, then the row's name.
