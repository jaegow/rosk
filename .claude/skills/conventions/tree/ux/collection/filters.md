# Filters

- Offer All in every filter group unless the server has no read listing every record; say why at the list when it is left out.
- A control that switches what a page lists, rather than narrowing it, is the page's head tabs, outside the filters.
- Typing a search returns every filter group to All; a pick made while searching narrows within it.
- Open an autocomplete filter on a first page of options before anything is typed.
- Label an applied free-value filter with its column's header, then the value.
- Clear all filters only from the applied-filters bar, never from an empty state.
- Where readers use few filters, pin those and offer the rest from a `+ Filter` checklist; a ticked filter draws before it with focus, unticking clears it, and `+ Filter` is never disabled.
- A read the server refused for a filter's value shows on that filter, with no toast.
