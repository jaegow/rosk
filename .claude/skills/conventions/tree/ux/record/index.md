# Place or step

A place is a routed view; a step is a dialog.

- Any of: an id worth pasting to a colleague; it outgrows the viewport or reads beside evidence; it can end in a state to act on later (a conflict, a partial save) → [place](place/index.md)
- All of: it fits without scrolling; its outcomes are save, cancel, delete or close; nothing about it is worth a URL → [step](step.md)

A nested edit opened from a record view is a step whatever its size ([nested](nested.md)); so is a create started from a group's add, whose saved record then opens in its place.
Unsure means place: a dialog that outgrew the test strands the user with no link, Back or reload.
