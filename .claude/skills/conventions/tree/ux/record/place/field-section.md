# Field section

- Show its records in their own sort; one just added shows first until reload.
- A section holding a form table keeps its head stuck over the scrolling rows, with every add and table-wide action in the head.
- An action on one record sits on its row, never in the head; the head only adds.
- A section showing one record's labelled values carries its Edit (or View) in its head.
- For linked records offer New and Add Existing (Choose Existing for one); for owned records one Add.
- Its table has a pinned actions column: Edit opens the record's modal, Delete or Remove asks first; Remove says the record itself stays.
