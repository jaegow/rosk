# Accessibility

- Keep every focusable descendant out of an `aria-hidden` container; never use `inert` to do it, since it also blocks the pointer an overlay catches.
- Give every route a page heading.
- Name an icon-only control in a tooltip shown on hover and keyboard focus after the standard delay.
- Name a control repeated down a list per row, starting with its visible word ("Edit Item 4"), so voice control still matches it.
- Never use colour as the only signal: a tone also shows its icon or words.
- Meet 4.5:1 for text and 3:1 for large text, a control's edge and a meaningful icon, in light and dark mode. A disabled control and a muted can't-run commit are exempt; their state reaches assistive tech.
- A region's not-ready state is a polite status; only an error is an alert.
